# 📊 Portal Web Corporativo - Fiscal Data

<img src="logofiscaldata.png" width="300">

## 📌 Objetivo del proyecto

El objetivo de este proyecto es desarrollar un **portal web corporativo** para la empresa **Fiscal Data**, especializada en asesoramiento y gestión fiscal para empresas y particulares.  

La página web permite mostrar los servicios de la empresa, facilitar el contacto con clientes y ofrecer una plataforma informativa clara y profesional.

> **Nota:** Este proyecto ha sido desarrollado como práctica colaborativa utilizando tecnologías de desarrollo web como HTML, CSS y JavaScript.

---

## 🏢 Tipo de empresa

**Fiscal Data** es una empresa dedicada a:

- Asesoramiento fiscal
- Gestión de impuestos
- Declaraciones tributarias
- Ayuda administrativa para empresas y particulares

La finalidad del portal es mejorar la presencia digital de la empresa y facilitar el acceso a sus servicios.
